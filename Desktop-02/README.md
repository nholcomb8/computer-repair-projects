# Desktop-02 – PC Platform Upgrade & Component Reuse

## Overview

This project involved upgrading an existing desktop computer to a newer hardware platform while reusing several components from the previous system. The goal was to improve overall system performance while retaining hardware that was still suitable for continued use.

## Previous System

The original desktop was built around an Intel i7-8700K platform. Before beginning the upgrade, I evaluated the existing components to determine which parts could be reused while balancing performance and cost.

## Component Reuse

The following components were transferred from the previous system to the new build:

* DDR4 RAM
* NVMe SSD
* SATA SSD
* NVIDIA GPU

Reusing these components allowed the upgrade to focus on replacing the hardware that would provide the most significant improvement while avoiding unnecessary replacement of functional components.

## Disassembly

I first disassembled the previous desktop and carefully removed the components that would be reused.

* Powered down and disconnected the system.
* Removed the graphics card.
* Removed the RAM.
* Removed the NVMe and SATA storage drives.
* Removed other components as needed.
* Inspected reused components before installing them into the new system.

## New System Assembly

I assembled the new system using the reused components along with the new motherboard, processor, case, and other replacement components.

The build included:

* New Intel i5-14400F CPU
* New ASUS B760M motherboard
* New case
* New power supply
* New CPU cooler
* Reused DDR4 RAM
* Reused NVMe SSD
* Reused SATA SSD
* Reused NVIDIA GPU

## BIOS & Windows Configuration

After assembling the system, I:

* Verified that the system successfully POSTed.
* Configured BIOS settings.
* Confirmed that the RAM and storage devices were detected.
* Booted into Windows.
* Installed necessary drivers and system updates.
* Verified that the reused hardware was functioning correctly.

## Testing

After completing the build, I tested the system to verify overall functionality and stability.

* Confirmed successful Windows startup.
* Verified CPU, RAM, GPU, and storage detection.
* Tested system performance under normal use.
* Monitored the system for stability and hardware issues.

## Result

The upgrade successfully transitioned the system to a newer hardware platform while allowing several existing components to remain in service. The completed system provided improved performance while making use of functional hardware from the previous build.
